# Sports Matchmaking

A React Native (Expo) app for finding nearby sports partners — profile creation, a map-based partner finder, matchmaking, and a player ranking view.

## Stack

- React Native + Expo
- TypeScript
- React Navigation
- react-native-maps
- NativeWind

## Screens

- **Home** — entry point and navigation hub
- **Profile** — profile creation/display (`ProfileForm`, `ProfileInput`, `ProfileDisplay`)
- **Map** — geographic discovery of nearby players
- **Match** — matchmaking flow
- **Ranking** — player ranking view
- **Contact** — contact screen

## Run locally

```bash
npm install
npx expo start
```
